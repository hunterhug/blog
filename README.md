# 阿星星✨的世界

自己 `DIY` 的网站主题，适合写写一些感受。

在 `_posts` 文件夹下面写文字即可。

## 如何配置

编辑 [config.yml](./_config.yml)。

## 如何启动

两种途径：

1. 托管于 `GitPage` 即可，仓库名为：`yourGithubName.github.io`，之后打开 `http://yourGithubName.github.io` 即可。
2. 安装 `Docker` 之后执行：

```
./docker_build.sh
./docker_run.sh
```

打开 [http://127.0.0.1](http://127.0.0.1)
